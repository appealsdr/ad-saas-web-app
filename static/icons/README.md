# App icons

Drop the attached PNG icons here with these EXACT names — the app references them
by these paths (served at `/icons/<name>.png`):

| File to save        | Used for                                  |
|---------------------|-------------------------------------------|
| `home.png`          | Sidebar → Dashboard (Home)                |
| `account.png`       | Sidebar → Accounts                        |
| `store.png`         | Sidebar → Stores                          |
| `case.png`          | Sidebar → Issues (case icon)              |
| `payment.png`       | Sidebar → Payments                        |
| `warning.png`       | Dashboard → "Documents Pending" warning   |
| `file.png`          | Every uploaded-file icon (case + store)   |
| `case_comment.png`  | Dashboard → "Latest Comments" item icon   |

Notes:
- The sidebar background is dark navy — the menu icons (`home/account/store/case/payment`)
  should be **white/light** so they're visible.
- `warning.png` and `file.png` appear on light backgrounds — they should be **dark/colored**.
- Export at 2× for crispness (e.g. ~40×40px for a 20px slot).
